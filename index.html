📖 使用说明

操作步骤

  1. 上传图片：点击上传区域选一张图，或拖入、Ctrl+V 粘贴。
  2. 选目标格式：WebP（体积最小）/ JPEG（兼容性最好）/ PNG（无损+透明）。 工具会自动识别源格式并推荐一个合适的目标。
  3. 调参数：质量滑块（JPEG/WebP 有效，PNG 忽略）、最大边长（等比缩小）。
  4. 处理透明背景：如果原图有透明区域且目标格式是 JPEG， 会出现「透明区域填充」颜色选择器（默认白色）。
  5. 下载：点「⬇ 下载图片」，文件名自动带正确的扩展名。

常见问题

Q：图片会被上传到服务器吗？
A：不会。所有转换都在你的浏览器里完成，图片不离开你的设备，断网也能用。

Q：PNG 转 JPEG 后透明背景变黑了怎么办？
A：本工具不会变黑——检测到透明区域会自动提示，并让你选填充颜色（默认白色）。 如果用的是别的工具出现黑块，那是因为它没做透明合成。

Q：JPG 能转成 PNG 变透明吗？
A：不能。JPEG 格式本身不存储透明信息，转成 PNG 只是换了容器， 原来的不透明像素依然是不透明的。要真正透明，只能用图片编辑软件抠图。

Q：转格式会损失画质吗？
A：取决于格式组合：
· 转 PNG 或 WebP（质量 100）→ 几乎无损失
· 转 JPEG → 有损，但质量 92 以上肉眼基本看不出
· JPEG 转 PNG → 不会变好，原图已有的压缩噪点会保留下来

Q：支持 HEIC（iPhone 照片）吗？
A：取决于你的浏览器。Safari 支持 HEIC 解码，Chrome/Edge 通常不支持。 如果上传后无法预览，说明当前浏览器不支持该格式的解码。

Q：会保留 EXIF 信息吗？
A：不会保留。Canvas 重绘会丢弃 EXIF，这同时帮你移除了位置隐私信息。

支持的浏览器

Chrome、Edge、Firefox、Safari 的较新版本。推荐 Chrome 或 Edge （WebP 编码支持最好）。
